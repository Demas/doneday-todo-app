## App name

DoneDay

## Short description

Plan today’s tasks, routines, birthdays, and reminders in one focused daily planner.

## Full description

DoneDay helps you make today count. Capture tasks quickly, organize them with lists, tags, priorities, subtasks, and due dates, then use daily views to focus on what matters now.

Use DoneDay in guest mode with your data stored on your device, or create an optional account to synchronize your planning data across supported devices. Export your data whenever you need a backup.

Features include:

- Quick task capture, editing, completion, undo, and recurring tasks
- Today, Upcoming, Overdue, and Completed views
- Priorities, categories, tags, subtasks, routines, and daily planning
- Birthday tracking and configurable reminders
- JSON and CSV export, plus JSON import
- Optional cloud synchronization and push notifications when configured

Device-native Smart Alarm availability depends on platform support, operating-system permissions, and device settings. Standard reminders remain available where a continuous native alarm is not supported.

## Store-review notes

- Guest mode is available immediately from the welcome screen.
- Account features are optional. A reviewer account, if needed, must be supplied through the store console, never committed to the repository.
- Android Smart Alarm permissions are requested only after a person explicitly enables Smart Alarm for a timed task or birthday.
- No ads or subscriptions are included in this release draft.
